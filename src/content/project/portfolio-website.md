A modern portfolio website with a unique retro terminal aesthetic. Features include:

- **Terminal UI**: Authentic terminal styling with blinking cursor and progressive loading
- **80s Retro Design**: Neon colors, glowing effects, and CRT-style scanlines
- **Interactive Elements**: Hover effects, click ripples, and smooth animations
- **Responsive Design**: Works seamlessly across all device sizes
- **Performance Optimized**: Built with Astro for lightning-fast loading

The site showcases my skills and projects while providing an engaging, memorable user experience that stands out from typical portfolio sites.
